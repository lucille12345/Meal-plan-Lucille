## Adding or correcting a price

1. Open [`public/ingredient-prices.js`](../public/ingredient-prices.js).
2. Find or add a line: `'ingredient name': {per:'100g', eur:1.10},` — key must be the
   ingredient's exact lowercase name as it appears in `recipes-db.js`.
3. `per` is one of `100g`, `100ml`, `piece`, `clove`, `slice`, `stalk` — whichever the
   ingredient is naturally priced by.
4. Run `node tools/build-prices-md.js` to rebuild this page.

A dish ingredient whose name isn't in this table simply prices at €0 rather than a guess —
check the terminal output of the build script, it lists anything used but unpriced.
